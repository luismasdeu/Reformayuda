# Fórmulas de gancho que funcionan en el nicho

Sacadas de los reels que más destacan (vidIQ, España, reformas y ayudas). Se actualiza cada semana.

Estructura obligatoria de cada reel: **clip 1 = pregunta** (enorme, sola, que la persona se reconozca: «¿Vas a…?», «¿Has…?») y **clip 2 = golpe** (lo que se juega: dinero, perder la ayuda, un error). Después, el contenido.

## Ejemplos para Obrayuda
- Pregunta: «¿Pensabas pedir una subvención para tu reforma… y ya has empezado la obra?» → Golpe: «Puede que ya hayas perdido la ayuda.»
- Pregunta: «¿Vas a cambiar las ventanas este año?» → Golpe: «Hacienda te devuelve hasta 3.000 €… si haces esto antes.»
- Pregunta: «¿Vives en Logroño y tienes que adaptar tu casa?» → Golpe: «Te pueden pagar hasta 8.000 €.»
